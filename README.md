# Mensa_Bestellungen

Schritt-für-Schritt-Weg: Entwicklung unserer Mensa-App ("CampusBiss")Schritt 1: Die Idee & Anforderung an die AppZiel: Eine einfache, digitale Vorbestell-App für die Mensa unserer Hochschule entwickeln, die intuitiv bedienbar ist, Mensa-Preise live berechnet und die Bestellungen direkt speichert.Kernfunktionen: Namens- und Matrikelnummer-Eingabe, Auswahl von Hauptgerichten, dynamische Toppings (nur beim Salatteller), Desserts, Unverträglichkeiten, Abholzeit (mit Validierung) und eine automatische Gesamtpreis-Berechnung.Schritt 2: Das Backend vorbereiten (Google Sheets & Apps Script)Google Sheet anlegen: Zuerst wurde eine Google-Tabelle erstellt und mit den entsprechenden Spaltenkopfzeilen (Zeitstempel, Name, Matrikelnummer, Hauptgericht, Beilage, Dessert, Unverträglichkeiten, Abholzeit, Gesamtpreis) versehen.Schnittstelle einrichten (Apps Script): Über Erweiterungen $\rightarrow$ Apps Script wurde ein kleines Backend-Skript (doPost) hinterlegt. Dieses Skript nimmt die eingehenden Daten entgegen und schreibt sie als neue Zeile in die Tabelle.Web-App veröffentlichen: Das Skript wurde als Web-App bereitgestellt („Jeder“ hat Zugriff), sodass die App von außen Daten dorthin senden kann. Die generierte Web-App-URL dient als Schnittstelle.Schritt 3: Entwicklung des Frontends (HTML, CSS & JavaScript)Struktur & Design (HTML5 & CSS3): Erstellung einer lokalen index.html-Datei. Das Design wurde modern und benutzerfreundlich gestaltet (z. B. große, klickbare Optionsfelder mit Icons, Preisschilder, ein auffälliger Checkout-Bereich und ein responsives Layout für Smartphones).Dynamische Logik & Validierung (JavaScript):Interaktivität: JavaScript sorgt dafür, dass sich das Topping-Menü für den Salatteller nur dann öffnet, wenn dieser auch ausgewählt wurde.Live-Berechnung: Jede Änderung an den Gerichten oder Extras aktualisiert sofort den Gesamtbetrag auf dem Bildschirm.Validierung: Clientseitige Prüfungen stellen sicher, dass z. B. die Matrikelnummer genau 6 Stellen hat und die Abholzeit im Mensa-Fenster (11:30–14:00 Uhr) liegt.Schritt 4: Verbindung von Frontend und Backend (API-Anbindung)Asynchrone Datenübertragung: Wenn der Nutzer auf „Kostenpflichtig vorbestellen“ klickt, fängt JavaScript den Klick ab (preventDefault()), damit die Seite nicht neu lädt.Fetch-API: Die Formulardaten werden per fetch()-POST-Request als JSON-Paket an die in Schritt 2 erstellte Google-Apps-Script-URL gesendet.Visuelles Feedback: Während der Übertragung zeigt der Button einen Lade-Spinner. Nach erfolgreichem Versand ploppt ein animiertes Bestätigungs-Modal (Pop-up) auf dem Bildschirm auf, das dem Nutzer den erfolgreichen Eingang der Bestellung signalisiert.Schritt 5: Persistente Speicherung & ErgebnisIm Hintergrund landen die Daten vollautomatisch in Echtzeit in Google Sheets. Jede Bestellung erzeugt eine neue Zeile mit exaktem Zeitstempel.Ergebnis: Eine voll funktionsfähige, KI-unterstützt entwickelte Web-App, die ohne komplexe Server-Infrastruktur auskommt und den gesamten Bestellprozess digital abbildet.
